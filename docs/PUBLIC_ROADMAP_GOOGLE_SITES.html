Current Focus

Reward Reveals And Chest Opening

The first shared reward reveal foundation is in place. The next goal is polishing chest openings, offline rewards, reward rarity details, and quick actions so every reward moment feels clear and satisfying.

Recently Finished

Finished

Shop, Inventory, And Armory Refresh

The shop and inventory were redesigned so they feel more like an RPG armory and less like long static lists.

  • Shop, Inventory, Armory, and Forge modes.
  • Grid-style item browsing.
  • Filters and sorting.
  • Equipped gear summary.
  • Item detail sheets with buy, equip, use, open, sell, upgrade, salvage, and fuse actions.

Known Issues And Fixes

Fixed Recently

Upgrade details now name the required material, gear details show who can equip each item, forge rewards have the right label, reward reveal badges are readable, and offline battle loot is now revealed on claim instead of silently added.

Known Issues

Hero gear picker parity, idle reward presentation polish, and dedicated chest-opening animation are still being tracked separately from future feature ideas.

Foundations Built

Foundation Built

Progression Pacing

Gear tiers now depend on player progress, biome progress, boss progress, and reward source, helping prevent high-tier gear from appearing too early.

Foundation Built

Biome Progress

The app can track biome layers, boss unlocks, boss victories, progress points, and first-clear reward state.

Foundation Built

Forge And Gear Upgrades

Gear now supports upgrade levels, rarity, traits, origin biome, salvage, and upgrade actions.

Working Next

Reward Reveal And Chest Opening Polish

Shared reward reveals now exist. Next is chest-first animation, offline reward accuracy, rarity/tier detail, and action buttons.

Gear Comparison And Locked Tier Messaging

Make gear choices easier by comparing selected gear against equipped gear and explaining what unlocks stronger tiers.

Boss-Gated Biome Progression

Use boss victories to unlock later zones, first-clear rewards, and stronger biome progression.

Planned Systems

Movement Mastery

Exercises level up individually and unlock passive perks.

Traits And Combat Effects

Gear, skills, runes, and mastery perks create tactical combat effects.

Class Skill Trees

Classes gain branches, skill points, and build identity.

Biome Layers

Cleared biomes return as harder layered zones with better rewards.

Ascension

A prestige loop that preserves meaningful history and grants permanent power.

Cosmetics And Avatar Visuals

Layered hero visuals, gear art, auras, titles, and cosmetic rewards.

Home Base

A room design system for trophies, decor, achievements, and personal style.

Exercise Catalog Trust

Better search, aliases, imports, machine support, and missing exercise reporting.

Feedback And Submissions

A privacy-friendly way for players to report bugs, request features, suggest workouts, and submit missing exercises or equipment.

What's New

A release notes screen for major features, fixes, balance changes, new exercises, new equipment, and watch app updates.
